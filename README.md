# Group Creator

Group Creator by BITBEAST PRIVATE LIMITED.

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/6a23b943098535027b9ba76c/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **Group Creator** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/6a23b943098535027b9ba76c/releases/latest) and reinstall.
